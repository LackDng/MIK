# ============================================================
# Tab: VLAN (Port VLAN membership)
# ============================================================
#
# Cổng SFP uplink → CORE: đặt T (Tagged) cho cả 6 VLAN
#
#   VLAN 10 → T | VLAN 20 → T | VLAN 40 → T
#   VLAN 50 → T | VLAN 60 → T | VLAN 70 → T
#
# Port 1–8 (access, tuỳ nhu cầu từng khu):
#   - Camera        → U cho VLAN 70, PVID=70
#   - IP Phone      → U cho VLAN 50, PVID=50
#   - TV/IPTV box   → U cho VLAN 40, PVID=40
#   - AP WiFi khách → PVID=60, U cho VLAN 60 + T cho VLAN 20
#                     (SSID Office dùng native 60, SSID Guest tag 20)
#
# Lưu ý SwOS: "T" = Tagged (trunk), "U" = Untagged (access)
#

# ============================================================
# Tab: Ports
# ============================================================
#
# Cổng SFP uplink:
#   PVID        : 1    (trunk không cần pvid)
#   RSTP        : ☑ Enable
#   Flow Control: disabled
#
# Vì sao BẬT RSTP (tài liệu cũ khuyên tắt):
#   Sau khi CORE đặt priority=4096, CORE luôn thắng bầu cử Root Bridge
#   bất kể MAC → CSS610 không thể cướp ngôi root nữa. Bật RSTP lúc này
#   an toàn và có thêm lợi ích: chống loop nếu ai cắm nhầm 2 cổng vào
#   nhau — rủi ro thực tế cao vì có tới 10 switch đặt rải ở các khu.
#   → Nếu firmware không có mục RSTP, để disabled vẫn chấp nhận được.
#
# Port 1–8 (PoE copper):
#   !! Cổng chưa gán VLAN sẽ nằm ở VLAN 1 và không đi đâu được.
#   !! Phải đặt PVID + gán VLAN ở tab VLAN trước khi cắm thiết bị.
#

# ============================================================
# Tab: PoE
# ============================================================
#
# Port 1–8 có PoE (802.3af/at):
#   - Disable PoE trên cổng không dùng để tiết kiệm điện
#   - Enable khi cắm AP WiFi, IP Phone, Camera
#   - Kiểm tra tổng PoE budget của CSS610-8P-2S+ trước khi cắm nhiều
#     thiết bị công suất cao (AP U7 LR ~20W, camera PTZ có thể >25W)
#

# ============================================================
# NOTES
# ============================================================
#
# 1. SwOS không có CLI – tất cả cấu hình qua Web UI
# 2. Sau khi cấu hình System tab → Apply → thiết bị reboot
# 3. Truy cập lại qua http://<IP> (cần PC trên VLAN10 hoặc VLAN60)
# 4. Backup config: System tab → Backup → lưu file .swb
#    → Đặt tên theo khu, VD "vila-5-6-20260804.swb"
# 5. Module SFP: S-31DLC20D hoặc tương đương (1G Single-mode)
#    Cáp: LC-LC Single-mode OS2
# 6. CSS610 KHÔNG hiện trong `/ip neighbor print` trên CORE (SwOS mặc
#    định không phát MNDP qua cổng vật lý). Xem qua tab Neighbors của
#    Winbox trên PC cùng VLAN10. Đây KHÔNG phải lỗi.
#
# ============================================================
# FIRST-TIME SETUP (nếu chưa có VLAN10 access)
# ============================================================
# 1. Cắm trực tiếp PC vào Port 1 (copper PoE)
# 2. Set PC IP: 192.168.88.x/24 (SwOS default: 192.168.88.1)
# 3. Truy cập http://192.168.88.1
# 4. Cấu hình System tab: IP=<IP mới>, VLAN=10, GW=192.168.10.1
# 5. Apply → reboot → cắm cổng SFP lên CORE CRS326
# ============================================================
