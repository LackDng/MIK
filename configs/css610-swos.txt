# ============================================================
# Tab: VLAN (Port VLAN membership)
# ============================================================
#
# Bảng VLAN membership – chỉ cần cấu hình Port 9 (SFP uplink):
#
#   VLAN 10 → cột Port 9: T
#   VLAN 20 → cột Port 9: T
#   VLAN 40 → cột Port 9: T
#   VLAN 50 → cột Port 9: T
#   VLAN 60 → cột Port 9: T
#   VLAN 70 → cột Port 9: T
#
# Port 1–8: chưa assign VLAN nào (để trống hoặc cấu hình sau)
#
# Lưu ý: Với SwOS, "T" = Tagged (trunk), "U" = Untagged (access)
#

# ============================================================
# Tab: Ports
# ============================================================
#
# Port 9 (SFP):
#   PVID        : 1    (default, trunk port không cần pvid)
#   Type        : Trunk
#   RSTP        : ☑ Enable   ← ĐỔI: trước đây để disabled
#   Flow Control: disabled
#
# Vì sao giờ BẬT được RSTP (trước khuyến nghị tắt):
#   Sau khi CRS326 (CORE) đặt priority=4096, CORE luôn thắng bầu cử Root
#   Bridge bất kể MAC. CSS610 không còn khả năng cướp ngôi root → bật RSTP
#   là an toàn và có thêm lợi ích: chống loop nếu ai đó cắm nhầm 2 port
#   vào cùng một switch.
#   → Nếu firmware SwOS không có mục RSTP, để disabled cũng chấp nhận được
#     (CSS610 chỉ có 1 uplink duy nhất, không có đường dự phòng).
#
# Port 1–8 (PoE copper – chưa dùng):
#   Để mặc định hoặc disable nếu cần bảo mật
#   !! Khi bắt đầu dùng: PHẢI gán VLAN cho port (tab VLAN + đặt PVID),
#   !! nếu không thiết bị sẽ nằm ở VLAN 1 và không đi đâu được.
#   !! Ví dụ cắm AP office: PVID=60, tab VLAN cột port đó chọn U cho VLAN 60
#   !!                      (nếu AP cần thêm SSID Guest thì VLAN 20 = T)
#

# ============================================================

# ============================================================
# 1. Cắm trực tiếp PC vào Port 1 (copper PoE)
# 2. Set PC IP: 192.168.88.x/24 (SwOS default: 192.168.88.1)
# 3. Truy cập http://192.168.88.1
# 4. Cấu hình System tab: IP=192.168.10.4, VLAN=10, GW=192.168.10.1
# 5. Apply → reboot → cắm Port 9 lên Core CRS326
