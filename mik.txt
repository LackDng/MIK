1. THIẾT BỊ & TOPOLOGY
=======================

Router:
  - MikroTik CCR2004-16G-2S+ (RouterOS v7)

  Port mapping:
  ┌──────────────────────────────────────────────────────────┐
  │ ether1          → WAN (PPPoE, cắm modem ISP)             │
  │ sfp-sfpplus1    → Core CRS326 (trunk all VLAN)           │
  │                   [Module S+31DLC10D - 10G Single-mode]  │
  │ sfp-sfpplus2    → dự phòng (chưa dùng)                   │
  │ ether2–ether10  → dự phòng (chưa dùng)                   │
  │ ether11–ether16 → VLAN 70 ACCESS (Camera/NVR trực tiếp)  │
  └──────────────────────────────────────────────────────────┘

Switch Core:
  - MikroTik CRS326-24S+2Q+RM (RouterOS v7)
  - Tất cả port cấu hình GIỐNG NHAU: trunk tagged all VLAN
  - Gắn port nào cũng được, đề xuất dùng:

  ┌──────────────────────────────────────────────────────────┐
  │ sfp-sfpplus1    ← Router CCR2004 (trunk all VLAN)        │
  │                   [Module S+31DLC10D - 10G Single-mode]  │
  │ sfp1            → CSS610  (trunk all VLAN)               │
  │                   [Module S-31DLC20D - 1G Single-mode]   │
  │ sfp2            → CRS328  (trunk all VLAN)               │
  │                   [Module S-31DLC20D - 1G Single-mode]   │
  │ sfp3–sfp12      → dự phòng (trunk all VLAN)              │
  │ sfp-sfpplus2    → dự phòng (trunk all VLAN)              │
  └──────────────────────────────────────────────────────────┘

Switch Access:
  - MikroTik CRS328-24P-4S+RM (RouterOS v7)
  ┌──────────────────────────────────────────────────────────┐
  │ sfp-sfpplus1    ← Core CRS326 (uplink trunk all VLAN)    │
  │                   [Module S-31DLC20D - 1G Single-mode]   │
  │ ether1–ether24  → chưa cấu hình access (để trống)        │
  └──────────────────────────────────────────────────────────┘

  ⚠️ Module S-31DLC20D là SFP 1G, cắm vào sfp-sfpplus1 (10G port)
     RouterOS sẽ auto-negotiate xuống 1G — hoạt động bình thường

Switch Access 2:
  - MikroTik CSS610-8P-2S+IN (SwOS)
  ┌──────────────────────────────────────────────────────────┐
  │ Port 9 (SFP)    ← Core CRS326 (uplink trunk all VLAN)    │
  │                   [Module S-31DLC20D - 1G Single-mode]   │
  │ Port 1–8 (PoE)  → chưa cấu hình access (để trống)        │
  └──────────────────────────────────────────────────────────┘

       │ S-31DLC20D (1G SMF)

5. VPN – CLIENT TO SITE (WireGuard)
=======================

Giao thức     : WireGuard (RouterOS v7 native)
Interface name: wg-vpn
Listen port   : UDP 13231
Server IP     : 10.10.10.1/24
VPN Pool      : 10.10.10.0/24

User: vanhau
  WireGuard peer allowed-address: 10.10.10.2/32
  Persistent-keepalive: 25

  ⚠️ WireGuard dùng keypair, KHÔNG dùng username/password
     Thay vào đó:
     - Sinh server private/public key
     - Tạo peer "vanhau" với placeholder public key
     - Comment rõ chỗ admin điền public key của client vanhau
     - Xuất kèm client config template đầy đủ trong comment

Client config template (xuất trong comment của config):
  [Interface]
  PrivateKey = <VANHAU_PRIVATE_KEY>
  Address    = 10.10.10.2/24
  DNS        = 8.8.8.8

  [Peer]
  PublicKey           = <SERVER_PUBLIC_KEY>
  Endpoint            = <WAN_IP>:13231
  AllowedIPs          = 10.10.10.0/24,
                        192.168.10.0/24,
                        192.168.0.0/24,
                        192.168.5.0/24
  PersistentKeepalive = 25

Routing VPN (split tunnel):
  Chỉ route các subnet nội bộ qua VPN:
  - 10.10.10.0/24   (VPN pool)
  - 192.168.10.0/24 (VLAN 10 Management)
  - 192.168.0.0/24  (VLAN 60 Office)
  - 192.168.5.0/24  (VLAN 70 CCTV)
  Traffic internet đi thẳng, KHÔNG qua VPN

Quyền truy cập VPN pool (10.10.10.0/24):
  ✅ VLAN 10  : full access
  ✅ VLAN 60  : full access
  ✅ VLAN 70  : chỉ 192.168.5.254:8054 và 192.168.5.253:8053
  ❌ VLAN 20,30,40,50: không truy cập

Firewall VPN (INPUT trên router):
  Accept UDP 13231 in-interface=pppoe-wan (WireGuard handshake)

Firewall VPN (FORWARD):
  Accept src=10.10.10.0/24  dst=192.168.10.0/24
  Accept src=10.10.10.0/24  dst=192.168.0.0/24
  Accept src=10.10.10.0/24  dst=192.168.5.254  dst-port=8054  protocol=tcp
  Accept src=10.10.10.0/24  dst=192.168.5.253  dst-port=8053  protocol=tcp
  Drop   src=10.10.10.0/24  (tất cả còn lại)

7. CCTV – VLAN 70
=======================

Access port: ether11–ether16 trên Router, pvid=70, untagged

Firewall VLAN 70:
  # NVR ra internet (port forwarding hoạt động)
  Accept src=192.168.5.254   out-interface=pppoe-wan
  Accept src=192.168.5.253   out-interface=pppoe-wan

  # Camera KHÔNG ra internet
  Drop   src=192.168.5.1-192.168.5.100  out-interface=pppoe-wan

  # VLAN 10 admin full access VLAN 70
  Accept src=192.168.10.0/24  dst=192.168.5.0/24

  # VLAN 20–60 và VPN xem NVR nội bộ
  Accept src=LOCAL_NETS       dst=192.168.5.254  dst-port=8054  protocol=tcp
  Accept src=LOCAL_NETS       dst=192.168.5.253  dst-port=8053  protocol=tcp

  # Drop tất cả còn lại VLAN 70
  Drop   src=192.168.5.0/24   inter-VLAN
  Drop   dst=192.168.5.0/24   inter-VLAN (trừ rule trên)

DST-NAT từ internet:
  WAN:8054 → 192.168.5.254:8054
  WAN:8053 → 192.168.5.253:8053

Hairpin NAT:
  Address-list LOCAL_NETS:
    172.16.20.0/22, 172.16.30.0/24, 172.16.40.0/24
    172.16.50.0/24, 192.168.0.0/24, 192.168.10.0/24
    10.10.10.0/24

  Phương án A (IP nội bộ trực tiếp – mặc định ENABLE):
    Forward rule: LOCAL_NETS → 192.168.5.254:8054
    Forward rule: LOCAL_NETS → 192.168.5.253:8053

  Phương án B (hairpin qua WAN IP – mặc định DISABLE):
    DST-NAT + SRC-NAT masquerade cho LOCAL_NETS → WAN-IP:8054/8053
    Comment rõ để admin enable khi cần

  172.16.50.0/24  → mark=voip

  Parent "wan-upload" max-limit=1000M
  ┌─────────────┬──────────┬──────────┬───────────┐
  │ Queue       │ Priority │ limit-at │ max-limit │
  ├─────────────┼──────────┼──────────┼───────────┤
  │ voip        │    1     │   2M     │  1000M    │
  │ iptv        │    2     │  50M     │  1000M    │
  │ wifi-mgmt   │    3     │  10M     │   200M    │
  │ office      │    4     │ 100M     │  1000M    │
  │ cctv        │    5     │  20M     │   100M    │
  │ guest       │    8     │   5M     │    50M    │
